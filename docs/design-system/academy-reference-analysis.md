# Academy Visual Reference Analysis

This document records the visual principles extracted from the approved Academy reference set. It is not a source to copy literally; it explains the shared grammar that should inform Hang Đôi Academy.

## Reference 01 — Editorial school poster / asymmetric course layout

Key observations:

- oversized typography is the first visual object;
- image is hard-cropped and partially subordinate to text;
- palette is warm and limited;
- shapes create movement between text and photography;
- information is organized as poster blocks, not cards;
- labels and small text act as metadata.

Academy takeaway:

- hero should lead with typography, not a UI card;
- use one dominant image crop and one supporting signal shape;
- metadata stays compact;
- avoid equal-width card layouts above the fold.

## Reference 02 — Bold geometry / modular learning composition

Key observations:

- simple geometry carries identity;
- circles, bars and blocks are used structurally;
- strong foreground/background contrast;
- type and shape align to the same grid;
- the layout feels playful without looking childish.

Academy takeaway:

- geometry should support hierarchy and direction;
- use circles/arches/capsules instead of icon libraries as the first choice;
- keep shapes large enough to matter;
- do not scatter many tiny decorative shapes.

## Reference 03 — Poster grid / mixed color fields

Key observations:

- multiple signal colors are used, but never equally;
- warm paper keeps the composition grounded;
- each colored block has a clear role;
- one or two areas dominate; the rest support;
- color is used to reset rhythm between information groups.

Academy takeaway:

- neutral/paper must remain the majority;
- green is the brand anchor;
- orange and cobalt can create secondary energy;
- yellow remains the smallest signal color, around 5–10%.

## Reference 04 — Image + type collage / educational storytelling

Key observations:

- images are cropped as graphic material;
- image, text and shape can overlap;
- captions and labels make the page feel editorial;
- hierarchy comes from scale contrast more than heavy UI chrome.

Academy takeaway:

- treat real Academy/Production photography as graphic blocks;
- allow controlled overlap;
- use caption/step number instead of enclosing every image in a card;
- radius is optional, not mandatory.

## Reference 05 — Dark field / manifesto treatment

Key observations:

- dark background creates one strong pause in the visual story;
- light type is very large;
- accent color is minimal;
- supporting copy is sparse.

Academy takeaway:

- use dark-green manifesto sections selectively;
- one long page may have one or two dark resets;
- yellow in dark sections should remain a marker, not become a second background.

## Reference 06 — Art-school brochure / printed matter feeling

Key observations:

- hard borders and offset print-like shadows;
- modest radius;
- visible hierarchy through blocks and labels;
- composition feels tactile and physical rather than glassy/digital.

Academy takeaway:

- poster cards may use hard 2px borders and 4–7px offset shadows;
- avoid glassmorphism;
- prefer flat fields and print detail;
- keep rounded, floating UI for product/admin surfaces only.

---

# Shared grammar across all references

The common system is:

1. **Large type first**
2. **Asymmetric composition**
3. **Warm base**
4. **One dominant brand color**
5. **Secondary signal colors**
6. **Yellow used sparingly**
7. **Real photography treated graphically**
8. **Simple geometry**
9. **Hard borders / print details**
10. **Alternating section rhythm**

This is the basis for Academy Design Tokens v2.
