# Academy Component & Layout Recipes

Use these recipes with `site/academy-tokens.css`.

## 1. Poster Hero

### Structure

Desktop:

```
12 columns

Headline: 7–8 cols
Image:    4–5 cols
Metadata: 2–4 cols
Shape:    overlap or crop edge
```

Required:

- Poster XL or Poster LG;
- one real image;
- one dominant shape;
- maximum two signal colors;
- yellow <=10%;
- one primary CTA.

Avoid:

- three CTA buttons;
- card stacks in hero;
- centered everything;
- generic gradient background.

## 2. Editorial Split

Preferred ratios:

- 7/5
- 8/4
- 5/7

Use for:

- why Academy;
- proof;
- program explanation;
- tuition/value;
- philosophy.

One side should be visually dominant.

## 3. Timeline

Use for:

- curriculum;
- journey;
- process;
- career progression.

Recipe:

- large number;
- thin line;
- one headline;
- one practice/detail block;
- optional evidence/result block;
- signal shape only on selected step.

Yellow should highlight one step, number or marker—not the whole timeline.

## 4. Poster Card

Use for marketing surfaces.

Tokens:

- radius: 8px;
- border: 2px ink;
- shadow: 4px hard offset;
- padding: 24px;
- background: paper / orange / cobalt / green.

Do not use yellow as the default poster-card background.

## 5. System Card

Use for forms/admin/structured data.

Tokens:

- radius: 12–16px;
- 1px border;
- no shadow by default;
- clean white/paper background.

Poster and System cards should not be mixed arbitrarily in one small cluster.

## 6. Gallery / Work Strip

Use 3–6 images with mixed aspect ratios.

Recommended rhythm:

```
portrait / wide / square / portrait
```

Add:

- small caption;
- project/category;
- step/sequence;
- output type.

Avoid:

- identical 4:3 cards;
- excessive radius;
- heavy shadows.

## 7. Manifesto Section

Background:

Green 950.

Foreground:

Paper 0.

Accent:

Yellow 500 at <=5%.

Text:

Poster Large / Display.

Supporting copy:

maximum 2 short paragraphs.

## 8. Signal Block

Orange or Cobalt are preferred for larger signal blocks.

Yellow is reserved for:

- sticker;
- small CTA;
- number;
- short highlight;
- tiny shape.

If a section already has a large orange/cobalt block, use even less yellow.

## 9. CTA Section

Recommended forms:

### Editorial CTA

- large heading;
- 1 primary CTA;
- 1 supporting sentence;
- geometric shape.

### Compact CTA

- one line;
- button;
- border top/bottom.

Avoid:

- pricing-style CTA unless the page is specifically transactional;
- yellow full-viewport CTA.

## 10. Navigation

Marketing navigation:

- simple;
- low chrome;
- 64–76px height;
- brand left;
- 3–5 links maximum;
- one CTA.

When page is highly editorial, navigation should disappear visually rather than compete.

## 11. Forms

Forms remain more system-like than poster-like.

Use:

- clean fields;
- 8px radius;
- 52px height;
- clear label;
- cobalt focus ring;
- green primary button.

Do not turn form fields into decorative poster blocks.

## 12. Image + Shape combinations

Approved:

- circle crop over rectangular image;
- arch crop beside large type;
- orange block partially behind image;
- green bar cutting across edge;
- tiny yellow sticker over image corner.

Avoid:

- more than three shape types in one viewport;
- all four signal colors at once;
- shape clutter around body text.

## 13. Mobile composition

### Hero

- headline first;
- image second or partially overlapping;
- metadata compact;
- shape moved behind edge, not centered.

### Timeline

- number stays large;
- content stacks beneath;
- no tiny multi-column text.

### Gallery

- horizontal scroll is acceptable only if intentional;
- otherwise single-column mixed crops.

### CTA

- one primary action;
- minimum 44px touch target.

## 14. QA checklist

A page is visually Academy-compliant when:

- [ ] warm paper or intentional dark green is the dominant canvas;
- [ ] green is the brand anchor;
- [ ] yellow occupies <=10% of composition;
- [ ] typography has clear scale contrast;
- [ ] at least one editorial/asymmetric composition exists;
- [ ] not every section is a card grid;
- [ ] shapes are structural, not decorative clutter;
- [ ] real imagery is preferred;
- [ ] image radius is not uniformly large;
- [ ] poster surfaces use hard borders/offset shadows;
- [ ] product/form surfaces stay clean/system-like;
- [ ] orange/cobalt are used as secondary signals only;
- [ ] mobile is recomposed, not merely shrunk;
- [ ] motion supports reading order;
- [ ] focus/reduced-motion accessibility is preserved.
