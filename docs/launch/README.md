# Media Career Program — Launch Content

**CURRENT PUBLIC MODE: INTEREST ONLY**

This folder contains launch content designed to create informed demand for Cohort 01 without implying that Formal Application, Selection, Admission or Enrollment is open.

## Operating rules

Use:

- Register Interest
- Learn about the program
- Get Cohort 01 updates

Do not use:

- Apply now
- Admission open
- Reserve your seat
- Enroll now
- Pay deposit

Primary CTA:

`Register Interest → academy.hangdoiproduction.com/media-career-program/`

Every distributed asset must use a Campaign Registry Content ID / UTM link.

## Content pack

- `cohort01-launch-content-pack.md` — first 10 priority assets.

## Distribution naming

If the same master creative is distributed on multiple channels, create distinct Content IDs.

Example master:

`reel01-career-gap`

Channel variants:

- `ig-reel01-career-gap`
- `fb-reel01-career-gap`
- `tt-reel01-career-gap`

This avoids merging channel performance into one attribution record.
