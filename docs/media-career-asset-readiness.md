# Media Career Program — Asset Readiness Workflow

## Purpose

Campaign Registry is also the production board for Cohort 01 launch creative.

Each campaign moves through five readiness gates before it should be considered ready to publish.

## Readiness gates

### 1. Brief

Check only when the creative has:

- objective;
- target candidate;
- key message;
- hook;
- CTA;
- Content ID;
- format;
- source/channel plan.

### 2. Production / Design

Check when the required raw production/design work is complete.

Examples:

- footage captured;
- photography captured;
- carousel layout completed;
- infographic designed;
- direct-outreach template prepared.

### 3. Edit / Final Asset

Check when the asset itself is ready for final review.

Examples:

- video edit locked;
- subtitles/graphics added;
- carousel export complete;
- static final export complete.

### 4. Copy / CTA

Check when:

- caption/copy is final;
- CTA matches current public mode;
- tracked URL/Content ID is correct;
- tuition/employment wording is not misleading.

Current public CTA:

**Register Interest**

### 5. QA / Approval

Final gate.

Verify:

- spelling;
- brand;
- mobile readability;
- link/UTM;
- legal-safe wording;
- no confidential client material;
- required permissions;
- publish channel/spec;
- owner approval.

## Readiness %

Each checked gate contributes 20%.

- 0% — not started
- 20% — brief ready
- 40% — production/design complete
- 60% — final asset complete
- 80% — copy/CTA complete
- 100% — QA complete

Readiness % is an operational indicator. It does not itself change campaign Status.

## Campaign status vs readiness

Recommended relationship:

### IDEA

Normally 0–20%.

### DRAFT

Normally 20–80%.

### READY

Normally 100%.

Do not set READY merely because a deadline is close.

### PUBLISHED

Requires:

- QA complete;
- publish URL recorded;
- correct tracked link used.

### PAUSED / ARCHIVED

May retain any readiness value; historical record should not be erased.

## Target Publish Date

Use target date to manage the launch sequence.

Recommended Content Pack 01 order:

1. Career Gap
2. Production Ready
3. Four-Month System
4. Role Map
5. Production Environment
6. Beginner FAQ
7. Tuition Value
8. Employment FAQ
9. Feedback/Rework
10. Who Is This For

The exact dates depend on the actual launch calendar.

## Asset type

Supported operational labels:

- REEL
- VIDEO
- CAROUSEL
- STATIC
- STORY
- DIRECT_OUTREACH
- PARTNER
- OTHER

These labels are for workflow/filtering, not legal classification.

## Review cadence

During launch production, review the board at least every working day.

Look for:

- campaigns with target date approaching but readiness <100%;
- READY campaigns with no publish URL after release;
- PUBLISHED campaigns with no traffic;
- creatives generating traffic but no Interest;
- duplicate Content IDs;
- missing owner.

## Legal Safe Mode QA

Before QA is checked, confirm the public wording still matches current system mode.

While public intake is `INTEREST_ONLY`, allowed CTA includes:

- Register Interest
- Get Cohort 01 updates
- Learn more

Do not approve creative containing:

- Apply now
- Admission open
- Enroll now
- Pay deposit
- Reserve your seat

unless public Formal Application has been explicitly unlocked in a reviewed release.

## Suggested ownership

One person should be accountable for each campaign even if multiple people work on it.

Owner responsibility:

- keep status accurate;
- maintain Asset URL;
- maintain target date;
- resolve production blockers;
- confirm Content ID before publish;
- add Publish URL;
- record learnings in Notes.

## Performance loop

After publishing:

```
Creative
→ Landing
→ Register page
→ Form Start
→ Interest
→ Candidate quality review
→ Learning
→ Next creative
```

Do not close the loop at reach/views alone.
