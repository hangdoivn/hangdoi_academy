# Media Career Program — Program Registration Pack

**DRAFT — AUTHORITY / COUNSEL REVIEW REQUIRED**

This folder turns the Official Program Document into reviewable appendices for program-registration readiness.

## Pack

- Appendix A — 16-week schedule
- Appendix B — module learning outcomes
- Appendix C — assessment rubric
- Appendix D — equipment / facility inventory
- Appendix E — trainer / mentor roster
- Appendix F — program appraisal / approval record
- Appendix G — certificate wording review

## Gate rule

Do not submit this pack to an authority until:

- program classification is confirmed;
- operating legal entity is confirmed;
- the competent registration process/database is confirmed;
- program document version is frozen;
- equipment/facility data are real, not placeholders;
- trainer evidence is collected;
- certificate/completion wording is legally confirmed.

The pack is intended to reduce preparation time, not replace authority-specific forms.
