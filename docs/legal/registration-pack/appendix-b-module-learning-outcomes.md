## Module 1 — Technical Foundation

On successful completion, the learner should be able to:

- set and verify basic camera exposure/focus;
- choose a lens for a defined shot purpose;
- establish a basic lighting setup safely;
- capture usable basic audio where required;
- operate entry-level grip/gimbal equipment safely;
- prepare cards/batteries/equipment before production;
- ingest, name, back up and organize files according to SOP;
- respond to technical feedback and rework an output.

Evidence:

- technical exercises;
- lighting task;
- equipment/SOP check;
- data-workflow gate.

## Module 2 — Commercial Production

On successful completion, the learner should be able to:

- interpret a simple commercial brief;
- identify priority shots;
- build usable coverage;
- execute an assigned photo/video task;
- adapt to subject/location constraints;
- direct a subject/talent at entry level;
- collaborate with assistants/operators;
- maintain production discipline and timing.

Evidence:

- commercial Photo assignment;
- commercial Video assignment;
- integrated F&B/Product/Hospitality/Lifestyle brief;
- production-behaviour observation.

## Module 3 — Post-production

On successful completion, the learner should be able to:

- select usable media;
- perform entry-level retouch/edit;
- create coherent pacing/story for the assigned format;
- perform basic sound cleanup/mix;
- apply basic colour correction/finishing;
- create required delivery versions;
- perform QC;
- archive/deliver according to workflow.

Evidence:

- photo post assignment;
- edit assignment;
- finishing task;
- QC/delivery gate.

## Module 4 — Production Ready

On successful completion, the learner should be able to:

- analyse a brief;
- research and build references;
- prepare moodboard/shot list/basic pre-production;
- operate within a simulated or approved production workflow;
- communicate issues;
- solve common production problems;
- complete a capstone from brief through delivery;
- identify an appropriate Primary Track and initial production role.

Evidence:

- pre-production pack;
- production simulation;
- capstone;
- final competency profile.

## Cross-program competency areas

Evidence should ultimately map to:

- C1 Technical Foundation
- C2 Visual & Commercial Judgement
- C3 Pre-production
- C4 Production Execution
- C5 Post-production & Workflow
- C6 Production Behaviour & Communication
- C7 Problem Solving & Reliability
- C8 Ownership & Business Awareness

Hard gates:

- Safety
- Data Integrity
- Serious Conduct
