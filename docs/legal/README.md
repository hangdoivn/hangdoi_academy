# Media Career Program — Legal Draft Pack

**STATUS: DRAFT — COUNSEL REVIEW REQUIRED — NOT FOR CANDIDATE USE**

This folder contains working drafts for the Legal & Enrollment gate of Hang Đôi Media Career Program.

Nothing in this folder authorizes:
- Formal Admission;
- tuition collection;
- payment/deposit requests;
- certificate promises;
- employment guarantees;
- use of learners in client work outside an approved educational arrangement.
