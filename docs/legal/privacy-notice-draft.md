## 2. Whose data is covered

This notice may apply to:

- people registering interest;
- applicants;
- Selection participants;
- admitted learners;
- enrolled learners;
- alumni where records are retained.

## 3. Data collected

### Interest / Application data

Possible categories:

- name;
- contact information;
- city;
- current education/employment status;
- Media experience;
- portfolio links;
- career interests;
- application answers;
- source/UTM attribution;
- candidate pipeline history.

### Selection data

Possible categories:

- assessment scores;
- assessor notes;
- interview notes;
- scheduling/attendance;
- candidate responses.

### Enrollment data

Only collect additional identity/document/payment data when legally necessary for Enrollment, invoicing, training administration or other approved purposes.

Avoid collecting unnecessary ID/health/sensitive data during the Interest stage.

## 4. Purposes

Possible mandatory program purposes:

- record interest;
- communicate official program updates;
- process Application/Selection when opened;
- assess eligibility/fit;
- schedule Selection;
- manage Admission/Enrollment;
- operate training;
- assessment and completion records;
- safety;
- accounting/invoice obligations;
- complaints/disputes;
- legal compliance.

Optional marketing purposes should use a separate consent mechanism where required.

## 5. Legal basis / consent

Final basis for each purpose must be mapped by counsel/data-protection reviewer.

Do not treat one broad checkbox as consent for every future purpose.

## 6. Recipients / access

Potential authorized recipients:

- Academy operations staff;
- assessors/mentors with need-to-know access;
- finance/accounting for approved payment/invoice tasks;
- IT/service providers acting under appropriate controls;
- competent authorities where legally required.

Hang Đôi Production personnel should not receive Academy candidate data merely because the organizations are related; access should follow purpose and need-to-know rules.

## 7. Third-party services

Document actual providers used for:

- hosting;
- database;

- file storage.

- data type;
- location/transfer;
- retention;
- contract/security basis.

If any service stores or processes personal data outside Vietnam, obtain legal review on applicable cross-border requirements before finalizing this notice.

## 11. Security

Operational controls should include:

- restricted admin access;
- secret/token management;
- encrypted transport;
- access logging where available;
- data minimization;
- incident handling;
- offboarding access removal;
- backup/security controls.

## 12. Marketing consent

Marketing consent must remain optional and separable from mandatory processing needed to record interest or operate the program.

A person who declines marketing should still be able to submit mandatory program information.
