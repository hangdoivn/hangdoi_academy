## 2. Program purpose

The program is designed to develop a career entrant from beginner/early-stage Media capability toward a **Production Ready** level suitable for participation in commercial Media-production environments under an appropriate role and level of supervision.

The program is not designed to claim that a learner becomes a Senior specialist in four months.

The program focuses on:

- technical Media foundation;
- visual/commercial judgement;
- pre-production;
- photography/video production;
- lighting/audio/grip;
- data and production workflow;
- post-production;
- commercial delivery/QC;
- production behaviour;
- problem solving;
- portfolio/capstone;
- career-role orientation.

## 3. Intended learner profile / entry requirements

- career entrants;
- students/recent graduates;

## 4. Program learning outcomes

A learner who successfully completes the program should be able to demonstrate the following competency areas at the applicable entry level.

### C1 — Technical Foundation

Demonstrate safe, reliable foundational use of:

- camera;
- lens;
- exposure;
- focus;
- lighting;
- audio;
- grip;
- gimbal;
- basic production equipment.

### C2 — Visual & Commercial Judgement

Interpret a brief and make visual choices appropriate to:

- subject;
- format;
- audience;
- commercial objective;
- visual hierarchy;
- mood/brand direction.

### C3 — Pre-production

Contribute to or prepare:

- brief understanding;
- research;
- reference collection;
- moodboard;
- shot list;
- basic production plan;
- equipment/asset preparation.

### C4 — Production Execution

Execute assigned Photo/Video tasks with appropriate:

- setup;
- framing;
- coverage;
- exposure/focus;
- lighting;
- production discipline;
- time awareness.

### C5 — Post-production & Workflow

Perform entry-level post workflow including:

- ingest/select;
- file organization;
- retouch/edit;
- basic sound;
- colour;
- graphics/multi-format output where applicable;
- QC;
- delivery/archive.

### C6 — Production Behaviour & Communication

Demonstrate:

- reliability;
- instruction-following;
- teamwork;
- respectful communication;
- feedback/rework behaviour;
- equipment discipline;
- client/location awareness.

### C7 — Problem Solving & Reliability

Identify and respond appropriately to common production variation such as:

- light/location change;
- technical failure;
- time pressure;
- missing asset;
- workflow problem;
- unexpected production constraint.

### C8 — Ownership & Business Awareness

At an entry level, understand:

- why a deliverable exists;
- what makes an output usable;
- deadline/quality implications;
- client/brand requirements;
- production-resource constraints.

## 5. Hard-gate outcomes

Regardless of aggregate score, the learner must meet minimum program requirements for:

### Safety

No unresolved material safety-risk behaviour.

### Data integrity

Demonstrated ability to follow required file/media/backup rules for the assessed scope.

### Professional conduct

No unresolved serious conduct issue incompatible with production participation.

## 8. Learning-method design

Planning model:

- approximately 20% instruction/demo;
- approximately 35% hands-on practice;
- approximately 25% commercial production lab/simulation;
- approximately 10% review/rework;
- approximately 10% career/production exposure.

These percentages are instructional-design assumptions and must be reconciled with the final legally registered program structure.

Core learning loop:

`Learn → Practice → Fail → Review → Rework → Produce → Pass Standard`
