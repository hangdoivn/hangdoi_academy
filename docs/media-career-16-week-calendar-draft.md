## Weekly operating rhythm

Recommended pattern:

1. concept / demonstration;
2. supervised practical;
3. individual/team execution;
4. review;
5. rework;
6. evidence recorded.

## Mentor capacity note

For a 10-person cohort, practical sessions should avoid one mentor becoming a single bottleneck.

Use:

- role rotation;
- small groups;
- peer observation;
- standardized evidence sheets;
- scheduled review blocks.

## Production exposure note

Do not insert real-client work into this calendar by default.

Real-client exposure should be added only when:

- legal/program policy permits;
- educational purpose is clear;
- supervision is available;
- client/confidentiality conditions are satisfied;
- learner work conditions are appropriate.
