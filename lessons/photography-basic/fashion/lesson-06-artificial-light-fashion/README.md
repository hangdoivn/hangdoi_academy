# Buổi 06 — Ánh sáng nhân tạo cơ bản cho Nhiếp ảnh Thời trang

**Thời lượng:** 150 phút

**Bài giảng:** https://academy.hangdoiproduction.com/bai-giang/nhiep-anh-co-ban/thoi-trang/buoi-06/

## File
- `index.html` — giao diện học viên có sơ đồ bố trí đèn, đối chiếu đèn liên tục/flash, popup giảng viên và checklist bài tập.
- `lesson-plan.md` — giáo án chuyên môn, timeline và hướng dẫn demo dành cho giảng viên.

## Giới hạn
- Một nguồn chính, thao tác setup an toàn.
- Chưa vào 2–3 đèn, TTL/HSS, gel màu và lighting ratio nâng cao.
- Ảnh minh họa (nếu có) để học cách nhìn; sơ đồ vị trí là mô phỏng, không thay demo thực tế.
