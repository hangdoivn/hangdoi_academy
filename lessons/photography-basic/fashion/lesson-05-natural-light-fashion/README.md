# Buổi 05 — Ánh sáng tự nhiên cho Nhiếp ảnh Thời trang

**Thời lượng:** 150 phút  
**Route:** `https://academy.hangdoiproduction.com/bai-giang/nhiep-anh-co-ban/thoi-trang/buoi-05/`

Buổi 04 được dùng để thực hành tổng hợp Buổi 01–03. Buổi 05 chuyển sang ứng dụng ánh sáng tự nhiên tại location thật.

## Trọng tâm
- scouting ánh sáng;
- open shade;
- doorway / window light;
- direct sun;
- backlight;
- bounce & negative fill;
- subject/background exposure;
- màu môi trường;
- bài chính: 1 location / 6 điều kiện ánh sáng.
